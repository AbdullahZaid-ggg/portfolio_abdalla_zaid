# Abdallah Zaid Portfolio

Standalone source code for the Abdallah Zaid personal portfolio website.

## Requirements

- Node.js 18 or newer
- npm, pnpm, or another Node package manager

## Install and run

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Production build

```bash
npm run build
npm run preview
```

The resume is in `public/HAAT_CV.pdf`, the profile image is in `public/avatar.jpeg`, and the main page is in `src/App.tsx`.
